# mcp_server

MCP Server exposing `submit_task`, `get_task_status`, `get_task_result`, `list_tasks`, `cancel_task`, `get_agent_status`, `list_agents`, `execute_workflow`, `create_video`, `get_video_status`, `get_system_status` to Claude Desktop. Implement a tool only once its backing functionality exists — no stub tools.

Owning requirements: FR-006, FR-011 in `../Requirement.md`.
